# VisionExpress – Optical Retail & Eye Clinic Management System

A full-stack web application designed to streamline optical retail operations, manual inventory tracking, prescription order verification, and clinic appointments.

🌐 **Live Application:** [https://visionexpressvercelapp.vercel.app](https://visionexpressvercelapp.vercel.app)

---

## Tech Stack & Cloud Architecture

* **Frontend:** React (Vite) — hosted on **Vercel** with custom API proxy rewrites
* **Backend:** Java Spring Boot (REST API) — hosted on **Azure App Service**
* **Database:** Cloud **MySQL** — managed via **Aiven**
* **CI/CD:** Automated production builds via **GitHub Actions** and Vercel Git integration

---

## Core Modules & Features

* **Online Shop & Sales Management:** Product catalog for frames, lenses, and sunglasses with manual administrative stock control and a prescription document upload and staff review workflow.
* **Doctor Appointment Management:** Real-time slot availability, patient appointment booking, and a doctor interface for managing schedules, consultation notes, and statuses.
* **Service Appointment Management:** Dedicated booking and tracking workflow for technician-led optical services such as frame adjustments, lens fittings, and repairs.
* **Member Loyalty & Rewards:** Automated loyalty point accumulation on eligible purchases, tiered membership tracking, and reward discount calculations.
